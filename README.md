# Kambaz Node Server App

This is the backend server for **Kambaz**, a learning management system (LMS) project built for **CS5610 - Web Development** at Northeastern University.

It provides APIs for handling courses, assignments, modules, and users.

## Tech Used

- Node.js
- Express.js
- JavaScript

## Setup

1. Clone the repo:

```bash
git clone https://github.com/KD7789/kambaz-node-server-app.git
cd kambaz-node-server-app
````

2. Install dependencies:

```bash
npm install
```

3. Start the server:

```bash
npm start
```

The server will run on:

```bash
http://localhost:4000
```

## Example API Routes

* `/api/courses`
* `/api/modules`
* `/api/assignments`
* `/api/users`
